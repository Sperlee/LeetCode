Repositório dedicado às minhas soluções para problemas do [LeetCode](https://leetcode.com/), com o objetivo de praticar **algoritmos, estruturas de dados e lógica de programação**.

## 🎯 Objetivos

- Praticar programação regularmente;
- Melhorar minha capacidade de resolução de problemas;
- Estudar e aplicar diferentes algoritmos e estruturas de dados;
- Analisar complexidade de tempo e espaço;
- Acompanhar minha evolução ao longo do tempo.
